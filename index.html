Introdução ao JavaScript

O que é JavaScript?

É uma linguagem de programação de alto nível e dinâmica, muito utilizada para criar aplicações interativas e sistemas de software.

No desenvolvimento web, trabalha especificamente com duas outras linguagens:

  • HTML
  • CSS

IMPORTANTE: JavaScript NÃO é Java!!!

Apesar das semelhanças dos nomes, são linguagens de programação totalmente diferentes.

O que dá pra fazer com JS?

Atualmente é possível trabalhar com o JavaScript das seguintes maneiras:

FrontEnd

  • Criar interfaces interativas
  • Menus
  • Validações
  • Filtros
  • Animações
  • Dashboards
  • Aplicações gerais com React, Vue, Angular e etc.

BackEnd

  • Criar API's
  • Autenticação
  • Integrações com serviços
  • Processamento de requisições
  • Integração com bancos de dados

Aplicações Mobile/Desktop

  • Aplicativos para celulares
  • Aplicativos para Desktops
  • Geralmente, utilizamos React Native ou Electron

Lembrete: A linguagem não fornece todos esses elementos sozinha. As possibilidades citadas acima dependem também do ambiente de execução, de API's, bibliotecas e frameworks utilizados.
